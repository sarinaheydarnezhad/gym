# همراه — MVP دستیار مربی

یک نمونه قابل‌اجرای فارسی و RTL برای پیگیری و تحلیل شاگردان مربی‌های مستقل بدنسازی و فیتنس.

## اجرا

```bash
npm install
npm run dev
```

آدرس پیش‌فرض: `http://localhost:5173`

## قابلیت‌های نسخه فعلی

- داشبورد «امروز چه کسانی نیاز به توجه دارند؟»
- موتور امتیازدهی شفاف بر اساس حضور، چک‌این، خواب، انرژی، تمرین، درد و آخرین ارتباط
- لیست، فیلتر، پروفایل و Timeline شاگردها
- توضیح دلیل هر هشدار و پیشنهاد اقدام بعدی
- فرم چک‌این هفتگی و به‌روزرسانی آنی تحلیل
- جست‌وجوی طبیعی فارسی در سوابق شاگرد
- افزودن شاگرد و یادداشت مربی
- ذخیره داده پایلوت در Local Storage مرورگر

## مرز نسخه پایلوت

این نسخه backend و ورود کاربر ندارد و برای نمایش و اعتبارسنجی workflow ساخته شده است. قبل از استفاده با داده واقعی باید احراز هویت، پایگاه داده رمزگذاری‌شده، رضایت شاگرد، سیاست نگهداری/حذف داده و پشتیبان‌گیری اضافه شوند.
